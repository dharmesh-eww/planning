# Motion System — GROVE

## Principle
Gentle, organic and purposeful. Motion should support a sense of progress and calm, never pressure or distract from safe movement.

## Timing
Micro 160–220ms; navigation 240–320ms; illustration reveal 450–800ms; progress path 700–1000ms. Use soft ease curves, no elastic overshoot.

## Signature interactions
Botanical line draws on welcome; daily card settles into place; weekly garden grows one leaf for an intentional completed activity; exercise illustration crossfades between steps; timer ring expands gently; journal entry slides into timeline; goal path reveals a small marker.

## Accessibility/performance
Respect reduced motion with static art. Avoid perpetual loops. Pause offscreen animations. Never use movement animation to communicate an exercise technique that is not also explained in text. Keep session controls responsive.
