# Navigation and Flows — GROVE

Tabs: My Day (daily plan), Move (exercise and routine library), Journal (session history and notes), Growth (goals and progress), Settings.

Onboarding: welcome → offline/privacy note → choose movement preference and weekly availability → choose gentle starter routine or create your own → My Day. All preferences optional.

Daily flow: My Day → planned movement card → exercise preview → start → log activity/sets → optional rest → finish → reflection note → Journal.

Plan flow: Move → browse/filter → routine detail → save/customize → schedule days.

Growth flow: select goal → choose date range → view consistency, time and personal performance trends → add reflection.

No shame-based streak loss. Rest days count as intentional days when scheduled. Persist sessions/timers locally and allow backup export/import.
