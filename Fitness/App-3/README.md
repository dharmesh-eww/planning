# Fitness — App-3: GROVE / Everyday Movement

**Concept:** GROVE — a gentle, nature-inspired movement journal for sustainable fitness habits.

A friendly offline-first workout planner with a softer editorial interface, illustrated movement guidance, gentle progress storytelling and habit-building interactions. No server, API, Firebase, account or cloud sync. SQLite stores private user data; GitHub can optionally distribute public content packs.
