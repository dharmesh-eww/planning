# Localization — GROVE

Languages: English, Hindi, Bengali, Gujarati, Kannada, Marathi, Nepali, Punjabi, Tamil and Telugu.

Use Flutter gen_l10n/ARB and generated accessors. Localize all user-visible text including movement cues, reminders, empty/error states, validation, timer announcements, chart summaries, accessibility labels and backup flows. No hardcoded UI strings. User-entered names and reflections remain unchanged.

Use locale-aware date/number/plural formatting; units remain a separate preference. Native-script language names, no flags. Validate typography, large text, contrast, screen readers, RTL readiness and reduced motion. Native reviewers must review exercise/safety language.
