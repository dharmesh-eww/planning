# Motion System — PULSE

Motion is rhythmic and purposeful, inspired by interval training. The active workout remains stable and readable.

Timing: micro 100–160ms; panel transitions 180–240ms; timer milestone 300–500ms; recap reveal 500–750ms. Avoid aggressive flashing, rapid scaling or motion that resembles a warning.

Signature interactions: pulse-line intro; segmented program timeline; exercise queue slides into active slot; set row snaps to completed state; timer ring advances continuously but quietly; milestone marker illuminates once; analytics draw on first view; recap uses a short radial sweep.

Lottie is reserved for intro, empty states, milestone and completion. Provide static fallback, pause offscreen, respect reduced motion, and never animate exercise instruction in a way that obscures safe form.
