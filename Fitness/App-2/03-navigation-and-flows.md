# Navigation and Flows — PULSE

Tabs: Overview (today's training), Programs (catalog and builder), Train (session launcher/active session), Insights (history and analytics), You (settings/data).

First launch: brand intro → privacy/offline note → units/equipment/training experience → select goal and weekly availability → choose a starter program or skip → Overview.

Training: program → session preview → warm-up note → start → exercise queue → log set → optional rest/interval → next exercise → finish → performance recap.

Builder: Programs → Create → split/week structure → add exercises → configure set targets, rest and tempo → reorder → save.

Insights: choose period → volume/frequency/performance → drill into exercise or session.

Persist session state and timer deadlines. Confirm discard. Never block the workout because network is unavailable. Use a local data export/import workflow.
