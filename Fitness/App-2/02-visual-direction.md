# Visual Direction — PULSE

## Concept
Dark Training Console: athletic, technical and immersive without sacrificing legibility.

## Palette
Midnight #0B1118; raised surface #141F2A; elevated panel #1B2A37; primary text #F3F7FA; muted #91A0AE; electric cyan #32D6E8; acid chart accent #C8F36A; coral alert #FF7468. Use accent colors sparingly and never as the only state cue.

## Typography
Condensed display face for short section headings; neutral sans for body; tabular numerals for load, reps and timer. Avoid long all-caps paragraphs.

## Layout
Dense enough for athletes, but prioritize one dominant task per screen. Strong grid, segmented panels, horizontal session timeline, high-contrast controls and large timer. Bottom navigation: Overview, Programs, Train, Insights, You.

## Signature components
Session command bar, exercise queue, set matrix, interval dial, PR marker, weekly volume chart, muscle-group filter chips and compact metric cards.

## Imagery
Dark studio / neutral cutout exercise photography with consistent lighting. Do not place text over busy photos. Use simple muscle diagrams where instructional accuracy matters.

## Accessibility
Contrast checked in dark theme, large controls, screen reader values for timers/charts, optional light theme, reduced motion and no color-only performance indicators.
