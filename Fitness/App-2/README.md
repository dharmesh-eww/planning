# Fitness — App-2: PULSE / Training Studio

**Concept:** PULSE — a dark, high-energy training console with bold typography, luminous data and kinetic interactions.

This is the same offline-first fitness product as App-1, but with a distinct visual language and more expressive session experience. No server, API, Firebase, account or cloud sync. SQLite is the source of truth; optional GitHub JSON distributes public catalog updates only.
