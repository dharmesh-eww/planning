# Screen-by-Screen Specifications — PULSE

## 01 Launch / privacy intro
Animated pulse line, concise product promise, offline/no-account assurance and Continue. Static fallback for reduced motion.

## 02 Training setup
Optional experience, equipment, location, training days, units and goal. Show Skip and explain local storage.

## 03 Overview dashboard
Dark hero for next session, weekly frequency/volume, recent PR (only if verified from saved history), recovery/rest-day note and quick start. Empty state suggests a starter plan.

## 04 Program catalog
Filter by strength, hypertrophy-style general training, conditioning, mobility, level, days and equipment. Cards show duration and equipment, not guaranteed results.

## 05 Program detail
Split layout, weekly schedule, exercise list, expected session length, equipment and edit/duplicate/start actions.

## 06 Exercise explorer
Search and filter by muscle, movement pattern, equipment and difficulty. Dense but scannable rows with thumbnail and tags.

## 07 Exercise detail
Large movement visual, muscles, setup, step sequence, breathing, common errors, alternatives and caution. Use text alongside visuals.

## 08 Program builder
Weekly split editor, exercise queue, drag reorder, target sets/reps/rest/tempo, validation and local save.

## 09 Session command screen
Current exercise, set matrix, load/reps controls, queue progress, rest shortcut, pause and finish. Prevent accidental finish; keep touch targets large.

## 10 Interval / rest dial
Large high-contrast countdown, segmented arc, pause/skip/+15/-15, optional sound/haptic and background-safe deadline persistence.

## 11 Session recap
Elapsed time, volume calculated from logged sets where comparable, completed exercises, optional effort and notes. Avoid misleading cross-exercise totals.

## 12 Training calendar
Week/month heatmap with accessible agenda list; planned/completed/rest markers and day drill-down.

## 13 Insights dashboard
Frequency, duration, exercise-specific load/reps trends, volume only when units are comparable, range selector and text summaries.

## 14 Exercise analytics
History by exercise, estimated max only if formula is explained and clearly labelled, personal bests and session links.

## 15 Measurements
Optional manually entered weight/circumference records, units, privacy hide toggle and dated trend. No diagnosis.

## 16 Goals
Weekly training frequency, session consistency or user-defined performance milestones. Edit/pause/complete; no guilt framing.

## 17 History
Filter by date/program/status; compact session cards and empty state.

## 18 Session detail
Set-by-set log, notes, edits and PR evidence. Keep historical record separate from current program edits.

## 19 Reminder center
Training-day schedules, local notifications, quiet hours, permission explanation and denied state.

## 20 Preferences
Units, theme, language, haptics, sounds, timer behavior, reduced motion, equipment and privacy.

## 21 Data vault
Export JSON/CSV, import with validation and preview, delete local data with explicit confirmation. No cloud sync.

## 22 Language picker
English, Hindi, Bengali, Gujarati, Kannada, Marathi, Nepali, Punjabi, Tamil and Telugu; native scripts and preview.

## 23 Content pack manager
Manual GitHub catalog check, version/changelog, download consent, schema validation, cache and rollback.

## 24 Shared states
Offline catalog, empty insights, timer recovery, import failure, storage failure, permission denial and unsaved changes; all localized.
