# Localization — PULSE

Languages: English, Hindi, Bengali, Gujarati, Kannada, Marathi, Nepali, Punjabi, Tamil and Telugu.

Use Flutter gen_l10n and ARB. Translate every label, dialog, error, validation, notification, timer announcement, chart summary, exercise instruction and accessibility label. Never leave static UI copy. User-authored names/notes remain unchanged.

Localize dates, numbers and plural forms. Keep kg/lb and distance units user-selectable independent of language. Native script language names, no flags. Validate dark theme contrast, text expansion, fonts, screen readers, reduced motion and RTL readiness. Native reviewers must verify exercise and safety terminology.
