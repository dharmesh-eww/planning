# Assets and Content — PULSE

Bundle the starter exercise catalog and essential imagery. Use consistent dark-studio photography or clear instructional diagrams. Keep text separate from images. Each asset records source, license, author, attribution, dimensions, locale and fallback.

Public GitHub content may include versioned exercise and program JSON, image manifests, checksums and changelog. App checks only on user request and retains last-known-good cache. No personal workout data is ever published.
