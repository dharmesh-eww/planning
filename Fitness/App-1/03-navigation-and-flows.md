# Navigation and User Flows

## Primary navigation
- Today: next workout, weekly activity, quick start.
- Plans: catalog, saved plans, custom builder.
- Train: active session and recent workout.
- Progress: history, trends, goals, measurements.
- Profile: preferences, reminders, equipment, units, data tools.

## First launch
Welcome/privacy → optional experience, equipment, location and units → training days → choose starter plan or blank plan → Today. Every preference step can be skipped.

## Workout flow
Today/Plans → plan detail → preview → Start → active workout → log set → rest timer → next exercise → finish → completion summary.

## Build plan
Plans → Create → name/schedule → add exercises → configure sets/reps/load/rest → reorder → save locally.

## Progress flow
Progress → time range → consistency/performance/measurements → chart and text summary → session detail.

## Data flow
Profile → Data & privacy → export or import backup / delete local data. Explain sensitive contents and confirm destructive actions.

## Rules
Persist active sessions and timer deadlines; save each set immediately; confirm discard; recover interrupted sessions. No core flow requires internet or sign-in.
