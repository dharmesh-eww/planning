# Assets and Content Strategy

Bundle a reviewed starter exercise library, muscle diagrams, empty-state illustrations, app icon, typefaces and static fallbacks. Exercise schema: stable ID, localized name/summary/instructions, muscles, equipment, difficulty, movement pattern, setup, numbered steps, breathing cue, common mistakes, substitutions, caution copy, image refs and content version.

Images must show accurate form, inclusive representation, consistent framing and uncluttered backgrounds. Use original or licensed assets with attribution metadata.

GitHub may publish versioned exercise-catalog.json, workout-plan-catalog.json, manifest, changelog and images. The app checks only on user action. GitHub distributes public content; it is not private storage.
