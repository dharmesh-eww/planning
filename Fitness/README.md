## Shared product constraints
- Flutter; SQLite (sqflite) is the source of truth for personal workout data.
- No custom API, server, Firebase, mandatory account or cloud sync.
- Offline-first; baseline exercise content ships in the app.
- Optional GitHub-hosted public JSON/image packs may update exercise and routine catalogs only. No personal data is uploaded.
- Local notifications and user-controlled JSON/CSV backup/import.
- Ten-language localization: English, Hindi, Bengali, Gujarati, Kannada, Marathi, Nepali, Punjabi, Tamil and Telugu.

Each plan contains product scope, visual direction, navigation/flows, detailed screen-by-screen specifications, architecture/data, motion, Lottie briefs, localization and asset/content strategy. The SVGs are editable vector planning references, not production Flutter screenshots. Lottie catalogs are specifications; actual Lottie JSON files are not included.
