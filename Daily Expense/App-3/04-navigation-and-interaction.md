# Navigation and Interaction

Bottom navigation: Home, Activity, Budgets, Insights, More. Persistent central Add action opens Expense, Income or Transfer.

Preserve tab state. Hide balances masks all sensitive totals and transaction amounts. Activity and Insights expose search/filter. All reads/writes update from SQLite immediately.

Use calm transitions and clear inline validation. Never report save success before local commit. Sync states always pair animation with text and actions.
