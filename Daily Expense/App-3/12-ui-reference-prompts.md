# UI Reference Prompts — Bloom Ledger

## Global prompt
Design a warm, nature-inspired personal finance journal. Use warm paper canvas, forest-green actions, sage cards, peach/amber accents, editorial typography, soft botanical vector illustrations and gentle rounded components. Layout feels like a thoughtfully designed planner, not a bank dashboard. Support ten locales, RTL, large text, light/dark themes and reduced motion. Avoid dark neon, excessive gradients, glassmorphism and childish mascots.

## Screen prompts
- Home: greeting, balance card, weekly cash flow, budget snapshot, recent journal and savings goal.
- Activity: paper-journal transaction timeline with date groups, category glyphs and filter chips.
- Add expense: amount-first form, friendly category tiles, account/date/note and clear forest save action.
- Budgets: stacked category cards with soft progress bars, exact remaining values and calm warning states.
- Insights: rounded area/bar charts, category breakdown and written summary.
- Goals: notebook-style goal cards, target/current values and progress arc.
- Settings: language, currency, theme, reduced motion, privacy and Sheets integration.
- Language picker: searchable native names in each script, no flags.
