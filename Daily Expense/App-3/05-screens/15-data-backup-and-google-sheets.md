# Data Backup and Google Sheets

## Purpose
Local export/import/backup plus optional Sheets. Explain exact access/data, choose spreadsheet, preview, confirm first transfer. Show sync state/errors and disconnect. No sync before consent.

## Layout and states
Use Bloom Ledger paper/sage/forest design tokens and restrained motion. Include default, loading, empty, validation, success, offline and reduced-motion/large-text variants. All labels, errors, hints and accessibility descriptions are localized. SQLite remains authoritative; core screen works offline.
