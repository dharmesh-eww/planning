# Add and Edit Transaction

## Purpose
Amount-first form with expense/income/transfer, category, account, date, note. Large touch targets, category icon grid, localized validation. Commit SQLite first; show short sprout/check Lottie afterward.

Include default, loading, empty, validation, success, offline and reduced-motion/large-text states where relevant. Localize every app-owned label, hint, error and accessibility description. Core data uses SQLite and works offline.
