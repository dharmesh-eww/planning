# Onboarding and Language Selection

## Purpose
Introduce privacy-first local tracking and language picker for ten locales. Display native self-names, no flags. Set currency independently. No account or Sheets prompt.

## Layout and states
Bloom Ledger warm-paper canvas, forest-green anchors, sage cards, editorial spacing and botanical accents. Include default, loading, empty, validation, success, offline and reduced-motion/large-text states where relevant. Localize every app-owned label, hint, error and accessibility description. Core data uses SQLite and works offline.
