# Core User Flows

## First launch
Splash → language selection → privacy explanation → currency and first account → Home. No account/network required.

## Record expense or income
Add → type → amount → category/source → account/date/note → Save → SQLite commit → small localized confirmation → updated balance and budget.

## Transfer
Choose source/destination → amount/date → validate → atomic local transaction. Exclude from income/expense totals.

## Budget and goals
Create category/period/limit → local save → progress card. Goals accept contributions and show steady progress without pressure.

## Insights
Choose range → chart reveal → drill down to source transactions → accessible localized summary.

## Optional Sheets
Explain access and exact fields → user initiates OAuth → choose/create spreadsheet → preview → choose export/sync → explicit confirm. Denial leaves app fully functional.

## Disconnect
Stop sync, clear local tokens/metadata, retain SQLite and remote Sheet. Explain remote collaborators can view its contents.
