# SQLite Schema Plan

Tables: transactions, accounts, categories, budgets, transfers, recurring_rules, savings_goals, sync_metadata, change_log, app_preferences. UUID text primary keys, integer minor-unit amounts, ISO currency, date/timestamps, tombstones, revision and sync state. Index date/category/account/type/updated_at; enforce foreign keys and migrations. Store locale/currency/theme/reduced-motion/privacy preferences locally. Tokens outside SQLite in secure storage.
