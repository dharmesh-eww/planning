# Navigation and Interaction

Bottom navigation: Home, Activity, Budgets, Insights, More. Persistent Add action opens Expense, Income, Transfer choices.

Preserve tab scroll/filter state. Hide-balances masks totals and transaction amounts. Search/filters available from Activity and Insights. All state reflects SQLite immediately.

Transitions are short and purposeful; reduced motion supported. Never show save success before SQLite commit. Sync status always includes text and retry/pause actions.
