# UI Reference Prompts — Motion Ledger

## Global direction
Design a premium personal finance mobile app with midnight #101820 canvas, elevated blue-charcoal surfaces, mint/cyan accents, coral expense signals, expressive tabular amounts, crisp typography and restrained luminous charts. Make it tactile and polished, not cluttered. Include light theme, reduced-motion, large text and ten localized scripts. Never use placeholder text or static English-only UI.

## Screen prompts
- Home: balance hero, income/expense split, budget ring, recent activity, prominent Add.
- Activity: grouped timeline, search, filters, type icons, sticky date headers.
- Add transaction: focused amount-first form, category grid, account/date/note, immediate save.
- Budgets: progress bars/rings, exact remaining amount, calm warning states.
- Insights: line/area chart, category breakdown, range selector and written summary.
- More: settings groups, language/appearance, backup and Sheets status.
- Language picker: searchable native self-names, no flags.
