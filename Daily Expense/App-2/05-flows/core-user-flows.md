# Core User Flows

## First launch
Splash → language selection → privacy/value intro → currency and first account → Home. No account/network required.

## Expense/income
Add → choose type → amount → category/source → account/date/note → Save → SQLite commit → small feedback → dashboard and budget update.

## Transfer
Choose source/destination → amount/date → validate → atomic local write. Never classify as income or expense.

## Budget and insights
Create period/category/limit → local save → progress appears. Insights show accessible charts and localized summaries.

## Optional Sheets
Explain scope/data → user taps Connect → native OAuth → choose/create spreadsheet → preview → choose export or sync → confirm first transfer. Denial leaves app fully functional.

## Disconnect
Stop sync, clear local tokens/metadata, retain SQLite and remote Sheet. Explain collaborators can read the spreadsheet.
