# Screen 09 — Budgets Overview

## Layout
Current budget period; total budget and spent/remaining; category budget cards; progress and alert states; create budget action.

## Behavior
Support monthly, weekly, and custom periods. Category budgets and overall budgets are distinct. Define whether transfers/refunds are excluded. Show actual amount, limit, remaining, and period dates.

## Acceptance
Budget totals use one currency at a time. Warning status includes text/icon and is not color-only. Empty state explains how to create the first budget.
