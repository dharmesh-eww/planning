# Screen 02 — Onboarding and Language Selection

## Purpose
Set language and basic financial preferences without requiring account creation.

## Steps
1. Welcome and privacy promise.
2. Language selection: English, Hindi, Bengali, Gujarati, Kannada, Marathi, Nepali, Punjabi, Tamil, Telugu.
3. Preferred currency selection; allow change later.
4. Optional starting account (cash/wallet/bank) and opening balance.
5. Optional default categories and monthly budget.
6. Explain optional Google Sheets connection, but do not ask permission during onboarding.

## Language picker
Searchable list. Show each language in its own script and its localized language name. Do not use country flags. Preview a sample amount/date in selected locale.

## Behavior
All selections save locally. Skip optional financial setup. Language and currency remain independently configurable. Do not infer currency solely from language.

## Acceptance
Every onboarding string is localized. No account, sign-in, or cloud permission prompt.
