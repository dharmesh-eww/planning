# Screen 12 — Calendar View

## Layout
Month/week calendar with locale-aware first weekday; daily income/expense totals; selected-day transaction list; add transaction action.

## Behavior
Selecting a day filters transactions. Month navigation updates summaries. Calendar date and number formatting follows locale. Do not use color alone to indicate days with activity.

## Acceptance
Support RTL calendar layout and localized weekday/month names. Offline data only.
