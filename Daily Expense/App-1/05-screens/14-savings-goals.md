# Screen 14 — Savings Goals

## Purpose
Optional goals for users who want to track a target amount.

## Layout
Goal title, target amount/currency, current saved amount, target date, progress, add contribution action.

## Behavior
Contributions should be represented transparently. If linked to an account, prevent double-counting as expense. Goals are optional and local.

## Acceptance
Do not provide investment advice or promise returns. Different currencies remain separate.
