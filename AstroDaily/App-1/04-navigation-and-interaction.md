# Navigation and Interaction

## Bottom navigation
1. Today — daily reading and reflection.
2. Zodiac — sign directory and profiles.
3. Explore — compatibility, lunar calendar and learning library.
4. Saved — favorite readings, signs and journal.
5. Settings — sign/date preferences, reminders, privacy, content updates and export.

## Global behavior
- Sign selector is available from Today and reading detail.
- Selected sign persists locally and can be changed at any time.
- Date/period selector makes the reading's coverage explicit.
- Preserve search query, filters and scroll position when returning.
- No sign-in, account gate or cloud sync.
- Back closes keyboard, popover/sheet, then screen.

## Interaction rules
- Daily reading cards show sign, date and period category.
- Weekly/monthly views clearly show start/end dates.
- Compatibility avoids numeric destiny/relationship scores.
- Journal is private local content; share excludes journal text by default.
- Lunar event timestamps show local time and source basis.
- Notification permission requested only after user enables a reminder.
- Offline state never blocks cached readings, journal or saved content.
- All controls have text labels; glyphs are not the only sign identifier.
