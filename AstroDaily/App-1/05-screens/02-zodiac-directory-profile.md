# Screen 02 — Zodiac Directory and Sign Profile

## Directory
12 signs in a clean grid/list with glyph, name and conventional date range. Search optional. Include clear accessible names alongside symbols.

## Sign profile
Symbol, date range, element, modality, ruling planet, short traditional overview, strengths/challenges framed as cultural/astrological associations, related readings and compatibility entry.

## Rules
Do not make deterministic claims about personality, health, success or relationships. For cusp dates explain that exact astronomical sign boundaries depend on year/time/location; let users choose manually. Support all 12 signs equally.
