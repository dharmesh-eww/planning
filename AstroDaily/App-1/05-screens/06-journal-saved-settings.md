# Screen 06 — Journal, Saved and Settings

## Journal
Prompt, date, free-text reflection, optional mood label/tags. Create/edit/delete/search. Private local-only. Never share journal content by default.

## Saved
Favorite readings, signs, learning articles, compatibility pairs and reading history. Preserve user references if remote content is updated or withdrawn; show unavailable state.

## Settings
Selected sign, optional birth date, reading categories, locale, daily/weekly/lunar reminder time, quiet hours, notification permission status, content update, privacy, export/import, legal/disclaimer and app info. No appearance/theme option.

## Data portability
Export selected profile/preferences, journal, favorites, reminders and history to versioned JSON. Import validates, previews, merges or replaces after backup. No automatic cloud backup.
