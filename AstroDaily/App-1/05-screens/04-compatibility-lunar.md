# Screen 04 — Compatibility and Lunar Calendar

## Compatibility
Choose two signs (including same sign). Show traditional element/modality themes, strengths, potential friction, and conversation/reflection prompts. Avoid scores, destiny labels, or “perfect match” claims. Add reminder that real relationships depend on people and context.

## Lunar calendar
Month navigation; new moon, first quarter, full moon, last quarter; event date/time in device timezone; source and dataset version. Event detail has educational context and optional reminder.

## Data integrity
Lunar events are precomputed editorial/astronomical data from a documented source. Never use a rough client-side formula or imply exact live calculation. If source timezone differs, disclose it and convert carefully.
