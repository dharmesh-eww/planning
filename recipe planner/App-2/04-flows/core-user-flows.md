# Core User Flows
## Quick discovery
Today → Discover/search → Results → Recipe Details → Save or Start Cooking.
## Cook from pantry
Discover → Cook with ingredients → Select available items → Find recipes → Review matches and missing items → Recipe Details.
## Plan meals
Plan → Select day/meal slot → Recipe Picker → Choose recipe → repeat → Generate grocery list → Review grouped ingredients → Save.
## Shop
Groceries → Open active list → Check items → Add missing custom item → Complete shopping.
## Cook step-by-step
Recipe Details → Start Cooking → Current step → optional timer → Next step → Finish → optional history record.
## Update content
Load local cache → fetch manifest → compare versions → download changed files → validate → transactionally import → show update result. On failure, preserve cached data.
