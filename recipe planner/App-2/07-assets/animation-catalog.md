# Animation and UI Asset Suggestions
Animations below are candidates, not downloaded or committed files. Preview each, verify its current licence, file size, dimensions, style, and Flutter-player compatibility before shipping.

## Search terms for additional UI assets
minimal food cooking, recipe book, grocery checklist, empty bookmark, calendar planning, download complete, sync success, timer, checkmark success, empty search, offline connection. Prefer flat/line art, limited colors, no embedded text, short loops.

## Placement
- Splash: none; prioritize fast launch.
- Onboarding: one small illustration, play once.
- Empty saved/collections: bookmark illustration.
- Planner empty state: calendar illustration.
- Grocery completion: short checkmark once.
- Content update: subtle sync animation only during sync.
- Timer: native numeric/progress animation.
- Cooking Mode: no Lottie; focus and readability first.

## Motion rules
Use sparingly. Under ~2 seconds for feedback. Never delay actions. Respect reduced motion with static fallback. No ambient loops on every screen. Bundle approved assets locally for offline use. Test low-end devices and lifecycle.

## Formats and licence
Lottie JSON is broadly portable. dotLottie is a compressed container with optional themes/state machines; confirm player compatibility. See [format guide](https://docs.lottiefiles.com/en/format).
Free public animations on LottieFiles are offered under Lottie Simple License, subject to terms; verify each asset's page. Attribution is encouraged. See [Lottie Simple License](https://lottiefiles.com/page/license) and [licensing basics](https://help.lottiefiles.com/animation-licensing-basics-).

For each approved asset record ID, creator, source URL, licence, download date, format, size, duration, dimensions, palette, attribution, static fallback. Download and test actual files; do not commit temporary preview/CDN URLs.
