# Screen Reference Image Prompts
Use these prompts to create consistent UI reference images for design review. App-2 must not reuse App-1's warm editorial art direction.

## Global prompt suffix
Modern minimal mobile UI, realistic Android/iOS smartphone screen, neutral white and very light grey surfaces, near-black text, muted evergreen accent, subtle dividers, accessible typography, generous whitespace, restrained corners, crisp high-fidelity UI, no clutter, no gradients, no glassmorphism, globally neutral food imagery.

## Priority reference screens
1 Today/Home: search, Cook with ingredients, next meal, compact recipe rows, five-tab navigation.
2 Discover: search, filters, category/cuisine shortcuts, concise results.
3 Recipe Details: compact food photo, title, timing, servings, ingredient list, Start Cooking.
4 Ingredient Finder: selected ingredients, search, Find Recipes, match results.
5 Weekly Planner: locale-neutral week strip and meal slots.
6 Grocery List: large checkboxes, quantities, groups, progress.
7 Cooking Mode: large step text, step count, timer, navigation.
8 Empty States: subtle bookmark/calendar/checklist Lottie-style art with no embedded words.

Generate all screens from one system: consistent spacing, typography, icon stroke, radii, navigation, and color roles. Use neutral sample content; avoid country-specific currency, flags, or defaults.
