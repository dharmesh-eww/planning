# Screen 13 — Timer
## Goal
Make cooking timers easy to set and monitor.
## Layout
Large remaining time; clear timer label; start/pause/reset controls; quick minute presets; optional sound/vibration preference.
## Behavior
Use monotonic/absolute time calculations so backgrounding does not pause elapsed time unexpectedly. Notify only with permission; in-app completion remains available. Respect device notification settings.
## UI generation prompt
Create a minimal timer screen with large remaining time, clear Start/Pause and Reset controls, a few quick presets, and a calm completion state. High contrast and no distracting motion.
