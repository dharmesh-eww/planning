# Screen 09 — Add Meal / Recipe Picker
## Goal
Choose a recipe for a selected planner date and meal slot.
## Layout
Context header showing date and meal; search; quick categories and filters; recipe list with compact rows; selected state; Add/Replace CTA.
## Behavior
If slot already contains a recipe, explain replacement before applying. Support custom meal note only if product scope includes it.
## UI generation prompt
Create a focused recipe picker screen for adding a meal to a selected day. Show date and meal slot context, a simple search field, compact filters, and scannable recipe rows. Make the final Add to plan action unmistakable and replacement behavior clear.
