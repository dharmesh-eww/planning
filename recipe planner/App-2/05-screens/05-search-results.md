# Screen 05 — Search Results
## Goal
Show useful, scannable results and make no-results recovery easy.
## Layout
Search query field; result count; selected filter chips; sort control; vertical recipe rows with image, title, total time, difficulty, cuisine/food type.
## States
Loading skeleton, results, no results with clear filters/suggested spelling, offline results from cache, content unavailable.
## UI generation prompt
Create a compact search results screen with a persistent search field, removable filter chips, sort action, and clean recipe rows. Make title and cooking time easy to scan. Include a helpful no-results state with a subtle illustration and clear reset filters action. Maintain minimal neutral styling.
