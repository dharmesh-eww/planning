# Screen 15 — Collections
## Goal
Organize recipes into personal groups.
## Layout
Title and Create collection; simple two-column or list collection tiles with name, recipe count, and optional cover thumbnail.
## Behavior
Create, rename, and delete collection. Deleting a collection never deletes its recipes or favorites.
## UI generation prompt
Create a clean collections screen with simple collection tiles, names, recipe counts, and a clear Create collection action. Use restrained thumbnails and avoid elaborate collage cards.
