# Screen 12 — Cooking Mode
## Goal
Provide a distraction-free step-by-step cooking experience.
## Layout
Recipe title and exit; step x of total and progress; large instruction text; optional step image; previous/next controls; timer action; adjustable text size.
## Behavior
Keep display awake only if user enables it. Timer continues correctly through app backgrounding. TTS is optional and user-controlled. Finish confirmation only if needed to avoid accidental completion.
## UI generation prompt
Design a distraction-free cooking mode screen. Use very large readable instructions, clear step progress, optional small step image, large Previous and Next controls, and a simple timer action. Minimal chrome, high contrast, and no ads or decorative animations.
