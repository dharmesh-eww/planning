# Screen 03 — Today / Home
## Goal
Give the user a calm, useful starting point rather than a promotional feed.
## Layout
Top greeting and profile/settings shortcut; prominent compact search; “Cook with what you have” action; next planned meal if one exists; small category shortcuts; one curated recipe recommendation; quick recipes list. Recently viewed appears only when available.
## Hierarchy
Practical actions first, recommendations second. Use compact recipe rows and one restrained image feature, not stacked hero banners.
## UI generation prompt
Create a clean, minimal recipe planner Today screen. Use a soft neutral background, dark readable text, muted green accent, compact search, a clear “Cook with what you have” action, next planned meal module, small category shortcuts, and concise recipe rows with appetizing thumbnails. Five-tab bottom navigation with labels. No dense dashboard, oversized hero, or excessive cards.
