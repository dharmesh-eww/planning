# Screen 02 — Onboarding & Preferences
## Goal
Set optional preferences with minimal effort.
## Layout
Simple progress indicator; concise headline; preference groups for dietary choices, cuisines, measurement system, and language only if not already selected by the device. Use selectable list rows/chips; Skip and Continue.
## Global behavior
All options are optional. Do not preselect a cuisine based on presumed country. Language selection shows native language names. Unit choice defaults to device locale but is editable. Explain settings can be changed later.
## UI generation prompt
Design a minimal onboarding flow for a worldwide recipe app. Use a clean white/soft-grey canvas, clear typography, compact preference rows, accessible selected states, and a simple progress indicator. Include optional dietary preferences, cuisine interests, metric/US customary choice, and Skip. No account creation, country assumptions, or permission prompts.
