# Screen 10 — Grocery Overview
## Goal
Show shopping lists and progress without clutter.
## Layout
Title and Add list action; active list summary with checked/total count and slim progress indicator; other lists in compact rows; empty state with Create a list.
## Behavior
Open list detail; create/rename/delete via menu. Do not show user-specific shopping data in ads or remote services.
## UI generation prompt
Design a minimal grocery overview with a clear active-list summary, simple progress indicator, and compact list rows. Include Create list empty state and a visible add action. Use neutral surfaces, readable text, and no decorative food photography.
