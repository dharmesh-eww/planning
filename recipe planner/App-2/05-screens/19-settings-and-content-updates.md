# Screen 19 — Settings & Content Updates
Goal: make global preferences, offline content, and privacy understandable.
Sections: language; metric/US customary; theme; dietary preferences; default servings; cooking text size; optional TTS; notification preferences; content version/last update; Check for Updates; privacy; licences/credits; clear image cache; reset local data.
Behavior: language/units apply immediately. Update failure preserves cached data. Cache clear never removes user data. Reset lists exact records removed and requires confirmation. No login/cloud sync.
UI prompt: Minimal settings with grouped rows and dividers. Include language, units, theme, cooking preferences, update status, privacy, local-data controls. Separate cache clear from reset. No account options.
