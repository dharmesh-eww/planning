# Screen 11 — Grocery List Details
## Goal
Support fast one-handed shopping.
## Layout
List title; progress count; grouped ingredient rows with large checkboxes; item quantity/unit; Add item action; optional category grouping and search.
## Behavior
Checked items remain visible with clear state; user may hide completed items. Quantity editing uses a sheet. Clear completed requires confirmation. Keep screen awake is optional.
## UI generation prompt
Create a highly usable grocery checklist screen for one-handed use. Large accessible checkboxes, strong item names, clear quantity and unit, subtle category headings, compact progress, and a prominent Add item control. Minimal visual noise; no ads.
