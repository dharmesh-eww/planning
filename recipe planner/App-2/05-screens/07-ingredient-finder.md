# Screen 07 — Ingredient Finder
## Goal
Find recipes using ingredients already available.
## Layout
Headline and explanation; searchable ingredient input; selected ingredient chips/list; optional use pantry items toggle; filters for max time and dietary preference; Find Recipes CTA.
## Results behavior
Show match percentage, matched ingredients, missing ingredients, and cooking time. Rank by match %, then fewer missing items, then time. Optional ingredients excluded from denominator. Allow adding missing items to grocery list.
## UI generation prompt
Create a minimal ingredient finder screen with a clear search field, selectable ingredient chips, optional pantry toggle, and one prominent Find Recipes action. Use simple ingredient icons only where recognizable. Keep the interface lightweight and globally neutral; do not imply location-specific ingredient availability.
