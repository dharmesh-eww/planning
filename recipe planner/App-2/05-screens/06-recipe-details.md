# Screen 06 — Recipe Details
## Goal
Present the information needed to decide and cook.
## Layout
Compact food image; title and description; time, difficulty, servings; favorite and overflow actions; ingredients section with serving stepper; ingredient rows with amounts and optional markers; ordered preparation steps; tips and verified allergen/nutrition details only if available. Sticky Start Cooking CTA.
## Behavior
Serving changes recalculate ingredient quantities without changing original recipe. Add to Plan and Add Missing Ingredients to Grocery are secondary actions.
## UI generation prompt
Design a clear minimal recipe detail screen. Use one accurate food photo, strong title, concise prep/cook metadata, a simple serving stepper, readable ingredient checklist, numbered instructions, and a clear Start Cooking button. White surfaces, thin dividers, muted green action color, and generous spacing. Avoid clutter and unsupported nutrition badges.
