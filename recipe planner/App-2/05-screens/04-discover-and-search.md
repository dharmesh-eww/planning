# Screen 04 — Discover & Search
## Goal
Make the full recipe catalog easy to explore.
## Layout
Search field at top; horizontally scrollable category shortcuts; cuisine and dietary filters; quick filter row for time/difficulty; curated recipe sections in compact list/grid toggle.
## Behavior
Search locally against downloaded content. Filters combine and show selected count. Preserve filters when opening a recipe and returning.
## UI generation prompt
Design a minimal Discover screen for an international recipe app. Keep search and filter controls prominent, categories compact, and recipe results easy to scan. Use clean dividers, small consistent thumbnails, concise metadata, and clear selected filter states. Avoid a busy magazine feed.
