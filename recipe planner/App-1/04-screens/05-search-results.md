# Screen 05 — Search Results

## Purpose
Present relevant recipes and make narrowing results effortless.

## Layout
- Search query field remains editable.
- Result count and active filter chips.
- Sort control and filter button.
- Recipe cards in a clean vertical list or two-column grid based on image quality and available width.
- Cards show image, title, total time, difficulty, and favorite affordance.
- Match query term subtly where useful.

## Filters
Cuisine, category/meal, dietary type, total time, difficulty, ingredients available, and optionally servings.
Use multi-select only when useful; provide Clear all and Apply.

## Behavior
- Sort by relevance, shortest time, popularity/curated order.
- Preserve query and scroll position when returning from details.
- Favorite action is immediate and reversible.
- Avoid claiming popularity based on user analytics; use curated ordering unless real data exists.

## Empty state
“No recipes found” + suggestion to remove a filter or try another term.

## UI prompt
Design a polished recipe search results screen with an editable search bar, compact active filter chips, clear sort/filter controls, and appetizing recipe cards. Each card should expose title, total cooking time, difficulty, and save action without crowding. Include a useful no-results state with a clear-filters action. Maintain a warm editorial visual system and strong readability.
