# Screen 19 — Settings & Content Updates
## Purpose
Make preferences, offline content status, and privacy controls understandable.
## Sections
Preferences: language, measurement units, dietary preferences, theme. Cooking: default servings, text size, keep screen awake, optional speech. Notifications: timer alerts/reminders; request permission only after user enables a feature. Content: last successful update, downloaded content version, Check for Updates. Privacy: explain local-only personal data and GitHub content downloads; privacy policy link. About: app version, licences/attributions. Local data: clear cache and reset data as separate actions.
## Behavior
Preferences apply immediately. Manual update reports success/failure. Cache clear must not delete favorites/plans/lists. Reset clearly explains what is removed. No login/account section.
## UI prompt
Design a clean Settings screen for a privacy-conscious offline-first recipe app. Group preferences into clear sections with simple rows and concise descriptions. Include a content-update panel showing last sync/version and a Check for Updates action. Separate cache clearing from full local-data reset and use careful confirmation. Do not include account, login, or cloud-sync settings.
