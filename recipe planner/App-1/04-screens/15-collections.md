# Screen 15 — Collections

## Purpose
Organize favorites into user-created groups such as Weeknight meals, Lunchbox ideas, or Festival recipes.

## Layout
- Title and Create Collection action.
- Collection cards with title, recipe count, and optional collage of up to three recipe thumbnails.
- Empty state with example collection ideas.

## Behavior
- Create and rename collection.
- Delete collection with confirmation; recipes remain in Favorites/catalog.
- Collection can be empty.
- Collection names are local and private.

## UI prompt
Create a warm, visual Collections screen where people organize recipes into personal groups. Use attractive thumbnail collages, clear collection names and recipe counts, and one obvious Create Collection action. Include a friendly empty state with examples. Avoid social sharing as a required feature.
