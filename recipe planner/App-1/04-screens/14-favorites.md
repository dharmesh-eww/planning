# Screen 14 — Favorites

## Purpose
Give users quick access to recipes they have saved.

## Layout
- Screen title and optional search.
- Filter/sort controls only when collection size warrants them.
- Recipe cards/list with image, title, time, and favorite state.
- Empty state with Explore CTA.

## Behavior
- Removing favorite is immediate and reversible.
- Preserve local favorites when remote content updates.
- If a recipe is no longer published, show an unavailable state and preserve the user's record.

## UI prompt
Design a beautiful, uncluttered Favorites screen for saved recipes. Use a simple title, optional search, and consistent recipe cards with clear image/title/time. The empty state should warmly invite users to explore recipes. Keep the experience personal and calm rather than turning it into a dashboard.
