# Screen 17 — Kitchen Inventory
## Purpose
Optional local pantry tracker to support Ingredient Finder and reduce duplicate purchases.
## Layout
Search/add ingredient field; category filters; inventory rows with ingredient name, quantity/unit, optional expiry date; low-stock/expiring labels only when meaningful; clear Add item action.
## Behavior
Inventory stays local. Ingredient Finder may use inventory as preselected ingredients. Do not decrement inventory automatically when a recipe is cooked; offer optional manual adjustment. Expiry reminders are opt-in and must not imply food-safety guarantees.
## UI prompt
Design a practical pantry inventory screen with a searchable add field, category filters, and clean rows showing ingredient, quantity, unit, and optional expiry date. Keep editing simple and make it clear this is a personal on-device list. Avoid alarmist food-safety claims or complex warehouse-style tables.
