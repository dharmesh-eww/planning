# Screen 18 — Cooking History
## Purpose
Help users revisit recipes they have cooked and repeat meals they enjoyed.
## Layout
Chronological list grouped by date/month; recipe thumbnail, title, cooked date, optional personal rating/note; search/filter only for large histories; empty state explains history is stored locally.
## Behavior
Add history on explicit completion. User can remove an entry or clear all with confirmation. History is optional and can be disabled in Settings.
## UI prompt
Create a simple Cooking History screen with a chronological recipe list, small food thumbnails, recipe title, and cooked date. Keep it personal and easy to revisit. Include a clear empty state and avoid social activity or streak pressure.
