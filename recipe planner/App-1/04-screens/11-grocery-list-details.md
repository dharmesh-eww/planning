# Screen 11 — Grocery List Details

## Purpose
Manage list name, items, sharing/export options, and list lifecycle.

## Layout
- Editable list title.
- Created/updated date in subtle metadata.
- Items grouped by category.
- Add item row.
- Overflow menu for rename, duplicate, export/share text, and delete.
- Optional notes.

## Behavior
- Changes persist immediately.
- Deleting list requires confirmation.
- Duplicate creates a separate local list.
- Share/export includes only the list content the user chooses to share; no background upload.
- Empty list supports quick add.

## UI prompt
Design a straightforward grocery-list detail screen. Keep the list title editable, items grouped with large checkboxes, and an obvious add-item action. Place rename, duplicate, export/share, and delete in a clearly labelled overflow menu. Use a restrained warm visual style and make destructive actions deliberate.
