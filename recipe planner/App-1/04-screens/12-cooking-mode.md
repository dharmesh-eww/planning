# Screen 12 — Cooking Mode

## Purpose
Turn recipe instructions into a distraction-free cooking companion.

## Layout
- Minimal top bar: recipe title, close, step count.
- Large step progress indicator.
- One instruction per screen/panel with 20–24sp readable text.
- Optional step image when provided.
- Timer action when step has duration.
- Large Previous and Next buttons; Finish on final step.
- Optional “Keep screen awake” control in settings/menu.

## Behavior
- Keep current step when screen rotates or app backgrounds.
- Timer continues according to platform lifecycle rules and notifies only if permission granted.
- Prevent accidental exit when a timer is running with a clear confirmation.
- Text size control available.
- Optional text-to-speech is user initiated.
- Mark recipe as cooked only on explicit Finish or user confirmation.

## UI prompt
Design a distraction-free cooking mode for use in a kitchen. Show one large, easy-to-read instruction at a time, clear step progress, and oversized Previous/Next controls. Make the timer action obvious when relevant. Use high contrast, generous spacing, minimal chrome, and no advertisements or unrelated navigation. Ensure the layout remains readable from a short distance and with large text settings.
