# Screen 16 — Collection Details
## Purpose
Browse and manage recipes inside one collection.
## Layout
Collection title and optional description; recipe count; recipe list/grid with remove action; Add recipes action; overflow menu for rename/delete.
## Behavior
Remove a recipe from this collection without unfavoriting it. Add opens recipe picker/search. Empty collection prompts Add recipes. Deleting collection does not delete recipes.
## UI prompt
Design a collection detail screen with a clear collection title, recipe count, and attractive recipe list. Provide Add recipes and simple remove controls. Make the distinction between removing a recipe from this collection and deleting the recipe itself unmistakable.
