# Screen 10 — Grocery List

## Purpose
Provide a fast, legible shopping checklist generated from meal plans or entered manually.

## Layout
- Active list name and list selector.
- Progress summary (e.g. 8 of 15 items).
- Add item action.
- Grouped sections: Produce, Dairy, Pantry, Spices, Other (categories come from content data).
- Large checkboxes and clear item/quantity text.
- Checked items move to a collapsed “Completed” section or remain visibly crossed out.

## Behavior
- Add custom items offline.
- Edit quantity/unit and category.
- Aggregate duplicate ingredients from meal plans only when units are compatible.
- Keep custom grocery items when regenerating; explain merge behavior.
- Clear completed items requires confirmation.
- Support swipe only as an optional shortcut; visible controls must remain available.

## Empty state
“Your list is clear” with Add item and Create from Planner actions.

## UI prompt
Design a calm, highly usable grocery checklist optimized for one-handed shopping. Show list selector, clear progress, a prominent add-item action, and grouped ingredient sections with large checkboxes and readable quantities. Completed items should be visually distinct but still recoverable. Keep the interface minimal and offline-friendly; no ads, clutter, or tiny tap targets.
