# Screen 18 — Cooking History

## Layout
Chronological list of completed recipes; date; optional rating/note; filters by date or collection; clear-history action.

## Behavior
Record history only when the user completes a recipe or explicitly chooses to save a cooking session. Allow delete individual entries and clear all with confirmation. Data remains local.

## Motion
Simple fade on deletion; provide undo when feasible. No celebratory confetti by default.

## Acceptance
Empty state links to recipes. Do not infer health, diet, or personal traits from history.
