# Screen 17 — Pantry

## Purpose
Optional local inventory to reduce duplicate grocery purchases.

## Layout
Ingredient search/add; categories; item rows with quantity and unit; optional expiry date; edit/remove actions; toggle to exclude pantry items from grocery generation.

## Behavior
Pantry is optional and never required. Support unknown quantity and “in stock” states. Do not infer expiry dates or food safety. Users control all item entries.

## Visual style
A simple kitchen index with clear category dividers. Avoid implying that a pantry quantity is exact when it is estimated.

## Motion
Subtle check feedback only; no animated jar-filling loops.

## Acceptance
Offline and local-only. Empty state explains optional value without pressuring setup.
