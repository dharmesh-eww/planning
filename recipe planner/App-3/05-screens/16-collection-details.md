# Screen 16 — Collection Details

## Layout
Collection name and edit action; optional cover; recipe count; recipe list; add recipes; sort and remove controls.

## Behavior
Add/remove recipes without affecting global saved status. Rename collection inline or in a small edit sheet. If an item is no longer in cached content, preserve a clear unavailable state.

## Motion
Adding a recipe may show a small ink check. Reduced motion uses direct state update.

## Acceptance
Empty collection offers Add recipes. Screen reader announces collection title and count. All membership changes are local.
