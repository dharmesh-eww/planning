# Screen 10 — Grocery Overview

## Layout
Current list summary; generate from planned meals; list groups; item counts; progress indicator; recent lists if supported. Use pantry-note visual cues sparingly.

## Behavior
Generate from selected date range and meals. Review aggregation before committing. Preserve units and source recipe references. Users can edit quantities and remove items already in pantry. All changes stay local.

## Motion
Progress may update with a small check-stroke animation. Never animate the entire list or delay check-off.

## Ads
No ads in grocery overview or list interaction.

## Acceptance
Clearly distinguish generated items from manually added items. Empty state offers Generate from plan or Add item.
