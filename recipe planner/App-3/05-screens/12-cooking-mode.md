# Screen 12 — Cooking Mode

## Purpose
Provide a focused, glanceable, step-by-step cooking experience.

## Layout
Recipe title and exit; progress indicator; current step number; large instruction text; optional step image; previous/next controls; ingredient checklist shortcut; timer action when relevant.

## Behavior
Keep screen awake only when user enables it and platform permits. Preserve step progress locally. Allow moving backward without losing completion state. Optional text-to-speech reads the current step. Timer can be started from a step and remains accessible.

## Visual direction
Warm dark-ink text on calm ivory or dark cocoa surface. No decorative paper texture behind instructions. Use large readable sans-serif body type and clear controls.

## Motion
No Lottie, page-turn, parallax, or ambient animation here. Step changes use immediate content replacement or a brief fade. Respect reduced motion.

## Acceptance
No ads. Large touch targets. Screen reader announces step changes and timer status. Instructions remain readable at large text sizes.
