# Screen 06 — Recipe Details

## Layout
Recipe image; title and short description; metadata for prep/cook/total time and difficulty; serving control; ingredients grouped by section; ordered instructions; optional verified nutrition/allergen details; save and add-to-plan actions.

## Behavior
Serving changes recalculate quantities only when scalable source quantities exist. Preserve fractions, ranges, and qualitative amounts. Ingredient check-off is optional and local. Start Cooking opens cooking mode. Add to Plan opens date/slot picker.

## Style
Recipe-page hierarchy with serif title, ruled section separators, and restrained hand-drawn ingredient details. Instructions and quantities remain sans-serif and high contrast.

## Motion
Serving number changes may use a brief crossfade. Save feedback can use a stamped check. No parallax on the hero image.

## Safety
Do not present dietary labels as guarantees. Show source/verification context for nutrition and allergen data.

## Acceptance
Long recipes remain readable; screen reader order follows content order; all actions have labels.
