# Screen 02 — Onboarding and Preferences

## Steps
1. Welcome: discover → plan → shop → cook.
2. Language: searchable list, language names in native scripts, no flags.
3. Units: metric or US customary.
4. Week start: locale suggestion with explicit choice.
5. Optional cooking interests, dietary filters, and skill level; skippable.
6. Starter content download: show approximate size and allow later.

## Visual direction
Recipe-leaf stepper, serif title, clear sans-serif labels, and small ingredient line illustrations. One primary action per step and visible Skip where appropriate.

## Behavior
Save choices locally; preserve them on back navigation. Never infer allergies or medical needs. Dietary filters are preferences, not safety guarantees. Offline onboarding uses bundled content.

## Animation
A small ingredient illustration can change between steps. Provide static artwork when reduced motion is active.

## Acceptance
Onboarding is skippable. Language, units, and week start are editable later. No login/account request. All controls expose accessible labels and selected state.
