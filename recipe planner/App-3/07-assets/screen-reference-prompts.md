# Original Screen Reference Prompts — App-3

Use these prompts to create a consistent original mockup set. They describe this design direction and do not request copying any existing app. Keep all mockups in the same device frame, typography, palette, and component system.

## Global visual prompt
Create a polished mobile recipe planner UI in the Modern Heritage Kitchen direction: contemporary recipe journal, warm parchment/oat canvas, ivory surfaces, deep roasted-brown ink, terracotta primary actions, muted olive status accents, restrained golden highlights, readable serif page headings, crisp sans-serif controls, modern recipe index cards, subtle ruled dividers, and delicate hand-drawn ingredient illustrations. Global audience, no country-specific cultural symbols, no flags, no text-heavy decorative scripts. Strong contrast, clear touch targets, realistic mobile spacing, premium but practical. Do not use gradients, glassmorphism, faux stains, or cluttered vintage ornament.

## Screen prompts
1. **Today:** daily meal slots, clear next action, small recipe suggestion, warm editorial heading, compact illustrated ingredient accent.
2. **Discover:** search field, category index, recipe shelves, clear filters, balanced photography and whitespace.
3. **Search results:** compact recipe cards, metadata, filter chips, clear sorting.
4. **Recipe detail:** beautiful food photo, title, timing, servings, ingredient groups, numbered steps.
5. **Ingredient finder:** selected ingredient chips grouped as Have/Exclude, matching recipe cards, obvious add control.
6. **Weekly planner:** seven-day layout with meal slots, recipe cards, add actions, legible date navigation.
7. **Groceries:** grouped checklist with clear check states, quantity/unit, no advertisements.
8. **Cooking mode:** focused large instruction text, step progress, timer action, no decorative imagery behind text.
9. **Timer:** large tabular countdown, simple progress ring, start/pause/reset.
10. **Kitchen:** saved recipes, collections, pantry, and history presented as clear index sections.
11. **Onboarding:** recipe-leaf progress indicator, one question per screen, ingredient line-art.
12. **Content updates:** version, download size, concise change summary, calm progress state.

## Animation storyboard prompts
- Sprig line-draw: 1–1.5 second brand reveal, then stop.
- Recipe-to-plan: small card travels a short distance into a selected meal slot; no full-screen flight.
- Grocery check: one short check stroke and subtle row state change.
- Empty collection: a small simmering pot illustration with one clear discovery action.
- Update success: page/leaf mark changes to a completed check, then remains static.

## Output consistency
Use one device size and safe-area convention across the set. Use realistic content, not lorem ipsum. Keep every label readable. Include light and dark theme variants, one RTL variant, and one reduced-motion static variant. Avoid generating any real brand logo or implying that suggested Lottie assets are already included.
