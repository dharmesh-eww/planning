# Screen 03 — My Pets, Pet Profile, Add/Edit Pet

## My Pets
List active profiles with photo, name, species, and next task. Provide add, archive, restore, and sort.

## Pet profile
Sections: overview, care schedule, care log, saved pet-specific guides, owner notes, optional vet contact.
Show data completeness as optional, never as a health score.

## Add/Edit fields
Name (required), species (required), breed/mix/unknown, photo, date of birth or estimated age, sex (optional), weight and unit, adoption date, notes, optional vet clinic/name/phone.

## Validation and privacy
Validate date and numeric ranges without making medical conclusions. Explain that profile data stays on this device. Avoid collecting microchip numbers or sensitive fields by default; if a free-text note is used, remind users not to store unnecessary sensitive information.

## States
No pets, one pet, multiple pets, archived pet, missing photo, invalid date, unsaved changes, delete confirmation.
