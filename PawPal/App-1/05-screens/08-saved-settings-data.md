# Screen 08 — Saved, Settings, Content Updates and Data Portability

## Saved
Favorites, custom collections, saved articles/breeds, reading history. All references are local; handle content removal without deleting user-created collections.

## Settings
Units, language (initially English US), notification preferences, quiet hours, content update settings, privacy, storage/cache management, app version, support and legal links. No appearance/theme setting.

## Content updates
Show installed content version, last successful check, available update size, and manual Check Now action. Do not run continuous background polling.

## Export/import
Export versioned JSON containing only user-selected local records. Import validates and previews, offers merge/replace, and creates a pre-restore backup.

## Data deletion
Delete one pet with dependent data preview; clear reading history/cache separately; delete all local data with clear confirmation. Removing app data does not affect GitHub content repository.
