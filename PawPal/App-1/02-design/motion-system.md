# Motion System

- Use motion to confirm state changes and clarify navigation, never to delay care tasks.
- Standard transitions: 180–220ms; sheets: 220–260ms; small press feedback: 100–140ms.
- Pet avatar/photo selection uses a brief crossfade.
- Completing a reminder updates the row with a subtle check transition and undo affordance.
- Save/favorite uses a short scale or icon-fill transition.
- Skeleton loading is static or low-motion; do not use shimmer when reduced motion is enabled.
- No confetti for health-related tasks or medication reminders.
- Respect Android system animation and reduced-motion preferences.
- All animations must remain understandable without motion.
