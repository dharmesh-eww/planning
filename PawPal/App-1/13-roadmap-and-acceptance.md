# Roadmap and Acceptance

## Release 1 — Core utility
Onboarding, pet profiles, Home, Discover, curated articles, breed directory, search, favorites, local reminders, settings, offline cache, privacy and safety disclosures.

## Release 1.1 — Care organization
Care logs, weight history, custom collections, export/import, expanded reminder recurrence, manual content update controls.

## Release 1.2 — Editorial expansion
More breeds, training programs, seasonal guides, adoption/new-pet checklists, senior-pet resources and reviewed FAQs.

## Later candidates (validate first)
Printable pet-care summary, widgets, calendar export, additional species, US Spanish localization. No cloud sharing or server.

## Acceptance
New user can create pet and read content without account; core personal features work offline; no user data uploaded; GitHub updates bounded/validated/reversible; reminders have clear recurrence; health content reviewed; light-only design; ads never block essential care.
